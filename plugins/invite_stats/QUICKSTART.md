# 邀请统计插件快速开始

## 第一步：启用插件

1. 打开框架的 Web UI（通常是 `http://localhost:8765`）
2. 进入"插件管理"页面
3. 找到 `invite_stats` 插件
4. 点击"启用"按钮

## 第二步：配置插件

### 基础配置（推荐）

如果机器人加入的群比较多，建议只在需要统计的群中启用：

```json
{
  "admin_qq": "你的QQ号",
  "enabled_groups": ["群号1", "群号2", "群号3"]
}
```

**示例**：
```json
{
  "admin_qq": "3302727375",
  "enabled_groups": ["123456789", "987654321"]
}
```

### 默认配置（所有群启用）

如果想在所有群中启用：

```json
{
  "admin_qq": "你的QQ号",
  "enabled_groups": []
}
```

## 第三步：测试插件

### 测试1：邀请统计

1. 在配置的群中，邀请一个新成员加入
2. 观察插件日志，应该能看到记录邀请的信息

### 测试2：查询记录

在群中发送：
```
邀请记录
```

机器人应该会回复你的邀请统计信息。

### 测试3：导出功能

使用配置的管理员QQ，私聊机器人发送：
```
导出统计
```

机器人会生成统计报告文件。

## 常用命令

| 命令 | 权限 | 位置 | 说明 |
|------|------|------|------|
| 邀请记录 | 所有群成员 | 群聊 | 查询自己的邀请统计 |
| 清空邀请记录 | 管理员 | 群聊 | 清空本群所有记录 |
| 月度结算 | 管理员 | 群聊 | 结算当月排行奖励 |
| 导出统计 | 管理员 | 私聊 | 导出所有数据 |

## 配置说明

### admin_qq（必填）
- **说明**：可以使用导出功能的管理员QQ号
- **类型**：字符串
- **示例**：`"3302727375"`

### enabled_groups（可选）
- **说明**：启用插件的群号列表
- **类型**：数组
- **默认**：`[]`（空数组表示所有群都启用）
- **示例**：`["123456789", "987654321"]`

## 常见问题

**Q：为什么配置了enabled_groups后，某个群不响应命令？**

A：检查该群号是否在 `enabled_groups` 列表中。如果不在，需要添加进去。

**Q：如何获取群号？**

A：可以在QQ中查看群资料，或者在Web UI的消息记录中查看。

**Q：更改配置后需要重启吗？**

A：通常不需要，框架会自动重载插件配置。如果没有生效，可以尝试在Web UI中重载插件。

## 技巧提示

### 💡 性能优化
如果机器人加入了很多群（50+），强烈建议配置 `enabled_groups`，只在需要统计的群中启用，这样可以：
- 减少内存占用
- 提高响应速度
- 减少不必要的数据存储

### 💡 数据备份
建议定期使用"导出统计"功能备份数据，导出的文件在 `plugins/invite_stats/temp/` 目录下。

### 💡 月底结算
插件会自动计算排名和奖励，但实际的泡点发放需要管理员根据导出的数据手动操作。
