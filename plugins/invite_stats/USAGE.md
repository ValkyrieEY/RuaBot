# 邀请统计插件使用指南

## 快速开始

### 1. 启用插件

在框架的Web UI中：
1. 进入"插件管理"页面
2. 找到"invite_stats"插件
3. 点击"启用"按钮
4. 配置管理员QQ号（可选，默认为3302727375）

### 2. 基本使用

#### 查询自己的邀请记录

在群聊中发送：
```
邀请记录
```

机器人会回复你的邀请统计信息，包括：
- 总共邀请的人数
- 还在群的人数（有效人数）
- 已退群的人数
- 邀请奖励（有效人数 × 1000泡点）
- 排行奖励（如果在前10名）

#### 清空邀请记录（仅管理员）

在群聊中发送：
```
清空邀请记录
```

只有管理员（配置的admin_qq）才能执行此操作，会清空本群所有的邀请记录。

#### 导出统计数据（仅管理员）

私聊机器人发送：
```
导出统计
```

只有配置的管理员QQ号才能使用此功能，会生成详细的统计报告。

## 工作原理

### 自动记录邀请

当有新成员通过**邀请**方式加入群时，插件会自动记录：
- 邀请人QQ号
- 被邀请人QQ号
- 加入时间
- 当前状态（在群/退群）

**注意**：只记录通过邀请加入的成员，不记录主动申请加入的成员。

### 排名规则

排名根据以下规则计算：
1. **首要标准**：有效人数（还在群的人数）- 降序排列
2. **次要标准**：总邀请人数 - 降序排列

这确保了不会有并列排名。

例如：
- A邀请了120人，在群60人，退出60人
- B邀请了100人，在群60人，退出40人

排名结果：A第一名（因为总邀请人数更多）

### 奖励计算

#### 邀请奖励
```
邀请奖励 = 有效人数 × 1000泡点
```

例如：邀请了100人，有效人数60人，则邀请奖励 = 60000泡点

#### 排行奖励（月底结算）
- 第1名：30000泡点
- 第2名：20000泡点
- 第3名：10000泡点
- 第4-10名：5000泡点

## 配置说明

在Web UI的插件设置中可以配置：

### admin_qq
- **类型**：字符串
- **默认值**："3302727375"
- **说明**：可以使用导出功能的管理员QQ号

### enabled_groups
- **类型**：数组
- **默认值**：[]（空数组，表示所有群都启用）
- **说明**：启用插件的群号列表

**配置示例**：

1. **所有群都启用**（默认）：
   ```json
   {
     "admin_qq": "3302727375",
     "enabled_groups": []
   }
   ```

2. **只在特定群启用**：
   ```json
   {
     "admin_qq": "3302727375",
     "enabled_groups": ["123456789", "987654321", "555666777"]
   }
   ```
   
   这样配置后，插件只会在这三个群中工作，其他群的邀请事件和查询命令都会被忽略。

**使用建议**：
- 如果机器人加入的群很多，建议配置 `enabled_groups` 只启用需要统计的群
- 这样可以减少不必要的数据记录和存储
- 提高插件性能和响应速度

## 常见问题

### Q: 为什么我邀请的人没有被记录？

A: 只有通过**邀请**方式加入的成员才会被记录。如果成员是通过主动申请加入群的，不会被记录。

### Q: 如何查看排行榜？

A: 目前没有单独的排行榜命令，排名信息会在查询邀请记录时显示（如果在前10名）。

### Q: 清空记录后能恢复吗？

A: 不能。清空操作是永久性的，建议在清空前先使用导出功能备份数据。

### Q: 导出的文件保存在哪里？

A: 导出的文件保存在插件的`temp`目录下，文件名格式为`invite_stats_YYYYMMDD_HHMMSS.txt`。

### Q: 月底结算是自动的吗？

A: 目前插件只记录数据和计算排名，实际的泡点发放需要管理员手动操作。

### Q: 如何让插件只在特定群中工作？

A: 在插件配置中设置 `enabled_groups` 参数，填入需要启用的群号列表。例如：`["123456789", "987654321"]`。如果留空（默认），则所有群都启用。

### Q: 配置了 enabled_groups 后，其他群的数据会丢失吗？

A: 不会。已记录的数据会保留，只是插件不再处理未在列表中的群的新事件。如果以后重新加入该群号，之前的数据仍然可以查询。

## 技术细节

### 数据存储

插件使用框架的Storage API存储数据，数据以JSON格式保存。

### 事件监听

插件监听以下OneBot事件：
- `notice.group_increase`：群成员增加
- `notice.group_decrease`：群成员减少

### API调用

插件使用以下OneBot API：
- `get_group_member_info`：获取群成员信息（用于验证群主权限）
- `send_group_msg`：发送群消息
- `send_private_msg`：发送私聊消息
- `upload_private_file`：上传文件（用于导出功能）
