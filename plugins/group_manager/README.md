# 小依群管插件

功能强大的QQ群管理机器人插件，为 XQNEXT 框架开发。

## 功能特性

### 🔐 授权中心
- 群授权管理（支持无限期和期限授权）
- 到期自动退群
- 到期通知主人/群内提醒
- 群开关机控制
- 卡密授权系统

### 👥 权限管理
- 四级权限体系：主人 > 管理员 > 群主 > 群管
- 同步QQ群管理权限
- 灵活的权限分配
- 身份查询功能

### ⚙️ 基础群管
- 踢人、禁言、解禁
- 上/下管理员（需机器人为群主）
- 全群禁言/解禁
- 清屏功能
- 批量撤回

### 🎫 入群管理
- **入群设置**：入群提示、入群禁言、入群私聊、入群改名
- **入群验证**：发言验证、数字验证、算数验证
- 免验证名单
- 最低等级限制
- 自动审核/同意/拒绝

### 🛡️ 安全系统
- **黑白名单**：支持全局和分群黑白名单，黑名单原因记录
- **违禁检测**：模糊和精准违禁词检测，支持撤回、撤回禁言、撤回踢出
- **刷屏检测**：时间窗口内消息频率检测，自动处罚
- **警告系统**：警告累积机制，达到限制自动处罚（禁言/踢出）

### 🤖 自动处理
- **自动撤回**：号码、文件、语音、视频、图片、链接、二维码
- **自动禁言**：检测特定类型消息自动禁言
- **自动踢出**：检测特定类型消息自动踢出
- 无视有权限用户

### 💬 问答系统
- 精准匹配和模糊匹配
- 支持全局问答和分群问答
- 灵活的问答管理
- 自动回复功能

### 🎨 名片系统
- 自动改名（入群时或发言时）
- 名片锁定（防止用户改名）
- 名片前缀设置
- 批量改名功能

### 📮 留言反馈
- 用户留言功能
- 反馈功能（自动通知主人）
- 留言/反馈查询和管理
- ID检索系统

### 🏆 头衔系统
- 自助头衔申请
- 头衔违禁词过滤
- 管理员授予头衔
- 恢复默认头衔

### 🔑 卡密系统
- 生成月卡/季卡/年卡
- 卡密使用和查询
- 自动增加群授权
- 使用记录追踪

### 🌐 远程管理
- 远程全体禁言/解禁
- 远程踢出/禁言用户
- 远程发送消息
- 跨群管理功能

### 📢 通知系统
- 艾特全体成员
- 艾特所有管理员
- 自定义通知内容

### 🔔 提示系统
- 入群/退群提示
- 上管/下管提示
- 被踢/被禁/解禁提示
- 改名提示

## 配置说明

在插件设置界面配置：

- `owner_qq`: 主人QQ号（拥有最高权限）
- `admin_qq_list`: 管理员QQ号列表（拥有全局管理权限）

其他所有设置都可以在群内通过指令配置。

## 数据存储

插件数据以JSON格式存储在 `plugins/group_manager/data/` 目录下：

- 每个功能对应一个JSON文件（如 `group_auth.json`、`permissions.json` 等）
- 数据可以直接编辑，支持手动修改
- 支持数据备份和迁移（复制 `data/` 目录即可）
- 详细说明请查看 [DATA.md](DATA.md)

**数据目录结构：**
```
plugins/group_manager/
├── data/                         # 数据目录
│   ├── group_auth.json          # 群授权数据
│   ├── permissions.json         # 权限数据
│   ├── blacklist.json           # 黑名单
│   ├── qa_system.json           # 问答系统
│   └── ...                      # 其他数据文件
```

## 使用方法

1. 在插件设置中配置主人QQ
2. 在群内发送"菜单"查看所有功能
3. 发送对应菜单名称查看详细指令（如"授权中心"、"权限管理"）
4. 主人/管理员发送"授权本群"或"本群开机"启用插件

## 权限说明

- **主人**：最高权限，可管理所有功能
- **管理员**：全局管理权限，可管理多个群
- **群主**（插件定义）：单群最高权限，可管理本群所有功能
- **群管**：单群管理权限，可使用基本管理功能
- **普通用户**：可使用问答查询、留言等基础功能

## 快速开始

```
# 1. 授权群聊
授权本群

# 2. 添加群管
加群管12345678

# 3. 设置问答
精准问你好答你好呀！

# 4. 开启入群验证
开入群验证
切换数字验证

# 5. 设置违禁词
加模糊撤回违禁词广告|推广

# 6. 查看菜单
菜单
```

## 注意事项

- 机器人需要群管理员权限才能使用踢人、禁言等功能
- 机器人需要群主权限才能使用上/下管理员、设置头衔等功能
- 主人和管理员需要在插件配置中设置
- 其他权限可在群内通过指令管理
- 未授权的群不会响应指令（授权相关指令除外）
- **截图桌面功能**：
  - 仅支持Windows系统
  - 需要安装依赖：`pip install pillow`
  - Linux系统会提示不支持
