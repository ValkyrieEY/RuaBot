# 每日泡点插件

## 功能介绍
这是一个群娱乐插件，允许群成员每日参与活动获取随机泡点数，支持特殊规则奖励。

## 功能特性
- **每日参与**：群成员每日可参与一次，获得1-666之间的随机泡点
- **特殊规则奖励**：
  - 豹子号（如111、222等）：额外奖励666泡点
  - 顺子号（如123、234等）：额外奖励222泡点
- **周累计统计**：统计每个用户一周内的总泡点
- **管理功能**：支持导出记录、周结算、清空记录等

## 使用说明

### 群成员指令
1. **我爱小狐仙** - 每日参与活动（每天0点刷新次数）
   - 随机获得1-666之间的一个数字
   - 根据获得数字给出相应祝福语
   - 触发特殊规则时给予额外奖励
   - 返回格式：`今日获得随机泡点(1-666)：XXX，额外泡点(特殊规则，如果没有，就显示0)：XXX`

2. **本周泡点** - 查询当前周累计泡点

### 群主指令
1. **导出泡点记录** - 导出txt格式记录用于核对
   - 格式：`XX|第1次获得泡点值|第2次获得泡点值|...|总共泡点值|`

2. **周结算泡点记录** - 显示所有人的周累计泡点（按高低排序）

3. **清空泡点记录** - 清空当前所有人的累计泡点记录

## 配置项
- `owner_qq`: 群主QQ号（拥有最高权限）
- `admin_qq_list`: 管理员QQ号列表
- `bubble_range_min`: 随机泡点最小值（默认1）
- `bubble_range_max`: 随机泡点最大值（默认666）

## 特殊规则说明
- **豹子号**：三位数字完全相同（如111、222、333等）
- **顺子号**：三位数字连续递增（如123、234、345等，注意231不算顺子）

## 权限说明
- 群成员可以使用基础功能
- 群主和管理员可以使用管理功能
