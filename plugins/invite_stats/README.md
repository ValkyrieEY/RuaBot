# 邀请统计机器人插件

## 功能介绍

这是一个用于统计QQ群成员邀请记录的插件，支持自动记录邀请人信息、查询邀请记录、排行榜和数据导出功能。

## 主要功能

### 1. 自动统计邀请记录

- 当有新成员通过邀请方式加入群时，自动记录邀请人和被邀请人的信息
- 记录加入时间、状态（在群/退群）、退群时间等详细信息
- 数据持久化存储，重启后不会丢失

### 2. 查询邀请记录

**触发指令：** `邀请记录`（所有群成员都可以触发）

**功能说明：**
- 查询自己的邀请记录
- 显示总邀请人数、有效人数（还在群的）、退群人数
- 计算邀请奖励：有效人数 × 1000泡点
- 如果在前10名，显示排行奖励

**回复格式：**
```
@查询人

---------------------------------------
共邀请：XX人
有效人数：XX人
退群人数：XX人
邀请奖励：XXXXX泡点
排行奖励：第X名：XXXXX泡点（仅前10名显示）
---------------------------------------
```

### 3. 排名规则

排名依据：
1. 首先按照**有效人数**（还在群的人数）降序排列
2. 如果有效人数相同，则按照**总邀请人数**降序排列
3. 确保不会有并列排名

排行奖励（月底结算）：
- 第1名：30000泡点
- 第2名：20000泡点
- 第3名：10000泡点
- 第4-10名：5000泡点

### 4. 清空邀请记录

**触发指令：** `清空邀请记录`（仅管理员可以触发）

**功能说明：**
- 清空本群所有的邀请记录
- 只有管理员（配置的admin_qq）才有权限使用此功能

### 5. 导出统计数据

**触发指令：** `导出统计`（私聊机器人，仅指定管理员可用）

**功能说明：**
- 导出所有群的邀请统计数据为txt文件
- 默认只有QQ号 `3302727375` 可以使用（可在配置中修改）

**导出格式：**
```
================DIVISION================
用户：<邀请用户qq> 累计邀请xx人 | xx人还在群内 | xx人已经退群
----
1. <被邀请用户qq> 被邀时间：x年x月x日x时x分x秒 | 状态：存在/退群 | 入群/退群时间：x年x月x日x时x分x秒
2. 以此类推
================DIVISION================
下一个用户以此类推
```

## 配置说明

在插件设置中可以配置以下参数：

- `admin_qq`: 管理员QQ号（可以使用导出功能的用户），默认为 `3302727375`
- `enabled_groups`: 启用插件的群号列表（数组类型），为空则所有群都启用

### enabled_groups 配置示例

**启用所有群**（默认）：
```json
{
  "enabled_groups": []
}
```

**只启用特定群**：
```json
{
  "enabled_groups": ["123456789", "987654321"]
}
```

这样插件只会在群 123456789 和 987654321 中工作，其他群的事件和消息会被自动忽略。

退群人数：60人

群主发送：

## 技术细节

### 数据结构

```json
{
  "group_id": {
    "inviter_qq": {
      "invited_qq": {
        "join_time": "2026年2月12日12时30分15秒",
        "status": "存在",
        "leave_time": null
      }
    }
  }
}
```

### 事件监听

- `notice.group_increase`: 监听群成员增加事件，记录邀请人信息
- `notice.group_decrease`: 监听群成员减少事件，更新退群状态

### 权限控制

- 查询邀请记录：所有群成员
- 清空邀请记录：仅管理员
- 月度结算：仅管理员
- 导出统计：仅指定管理员（私聊）

## 注意事项

1. 只统计通过**邀请**方式加入的成员（`sub_type == 'invite'`），不统计主动申请加入的成员
2. 排名计算时，优先考虑有效人数（还在群的人数），其次考虑总邀请人数
3. 导出功能生成的文件保存在插件的 `temp` 目录下
4. 数据通过 PluginAPI 的 Storage 功能持久化存储
